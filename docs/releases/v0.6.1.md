# 拾题 v0.6.1 · 标签管理与搜索改进

标签管理、搜索筛选和账号数据保护更新；发布与更新通道改用受信任签名流水线。

- 标签筛选和错题编辑使用可搜索、多选的标签弹窗；点击“确定”提交，点击“取消”或关闭弹窗放弃暂存选择。
- 支持申请公共标签，维护者审核后写入共享目录；增加申请去重、审核权限检查和目录并发冲突保护。
- 支持题号、关键词、平台、作者、标签和平台原生难度组合筛选，并优化结果相关性排序。
- 加强凭据保存、账号切换和本地记录归属校验，降低不同账号间记录误用或覆盖风险。
- 修复旧更新事务阻塞启动的问题，改进应用包变更后的恢复处理。

验证：发布工作流在 Windows、Linux x64/ARM64 与 macOS Intel/Apple Silicon 上执行检查、测试与构建；签名清单由独立作业使用仓库 Secret 生成，并在打包前验证签名、版本、Electron runtime 与 SHA-256；各平台安装包注入同一份已签名应用字节。安装程序未进行 Windows Authenticode 签名。

下载 `QMX-Notebook-Setup-0.6.1.exe` 运行安装，或解压完整 `QMX-Notebook-Windows-x64.zip` 使用便携版。安装会保留个人数据；Windows 安装程序无需管理员权限。GitHub Source code 是源码，不是可运行客户端。

更新说明：发布本 Release 后需在 Actions 运行 **Prepare published update channel** 并合并生成的更新通道 PR，`feed/manifest.json` 才会切换到本版本，现有客户端届时在“检查更新”中即可升级。Electron runtime 保持 40.10.6，无需重新安装完整客户端。
