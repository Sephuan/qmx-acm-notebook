# QMX Notebook v0.6.0

> Release status: source pushed; the GitHub Release, installers, and in-app update are not published yet. Complete signing-feed and installer validation before publishing.

## Highlights

- **Tag selection:** Tag filtering and problem editing use a searchable, multi-select dialog. Selections are staged until Confirm; Cancel or closing the dialog discards them.
- **Tag requests and review:** Users can request public tags. Maintainers can approve requests into the shared catalog. Duplicate requests, reviewer permissions, and catalog write conflicts are checked.
- **Search and filters:** Search by problem ID and keywords; combine platform, author, tag, and native difficulty filters. Result relevance ordering is improved.
- **Account and local-data protection:** Strengthens credential persistence, account switching, and local-record ownership checks to reduce cross-account data exposure or overwrites.
- **Startup and update recovery:** Prevents stale completed update transactions from blocking startup and improves recovery after application archive changes.
