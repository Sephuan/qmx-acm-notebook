# 拾题 v0.6.0 · 标签管理与搜索改进

标签管理、搜索筛选和账号数据保护更新。

- 标签筛选和错题编辑使用可搜索、多选的标签弹窗；点击“确定”提交，点击“取消”或关闭弹窗放弃暂存选择。
- 支持申请公共标签，维护者审核后写入共享目录；增加申请去重、审核权限检查和目录并发冲突保护。
- 支持题号、关键词、平台、作者、标签和平台原生难度组合筛选，并优化结果相关性排序。
- 加强凭据保存、账号切换和本地记录归属校验，降低不同账号间记录误用或覆盖风险。
- 修复旧更新事务阻塞启动的问题，改进应用包变更后的恢复处理。

验证：标签目录与审核后端 13 项测试通过；标签选择、错题表单和标签申请 UI smoke 测试通过；完整单元测试 143 项通过；Source checks 通过。Windows x64 安装程序和便携包已在本地构建并核对版本为 0.6.0；安装程序未进行 Windows Authenticode 签名。

下载 `QMX-Notebook-Setup-0.6.0.exe` 运行安装，或解压完整 `QMX-Notebook-Windows-x64.zip` 使用便携版。安装会保留个人数据；Windows 安装程序无需管理员权限。GitHub Source code 是源码，不是可运行客户端。

当前应用内更新仍未启用。更新清单使用 Ed25519 签名，必须使用与客户端内置公钥匹配的原私钥重新生成 `feed/manifest.json` 和 `resources/app.asar` 后才能推送；当前默认分支仍保留 v0.5.2 配套的已签名更新文件。不要用未签名或错误密钥的文件替换现有更新文件。
