# 拾题 QMX Notebook v0.6.0

> 发布状态：源码和 Windows x64 便携包已推送至 GitHub Draft Release。安装程序及其他平台安装包的 Actions 构建失败，尚未正式发布。应用内更新也尚未发布。

## 更新内容

- **标签选择体验**：标签筛选和错题编辑统一使用可搜索、多选的标签弹窗。选择暂存至点击“确定”；点击“取消”或关闭弹窗则放弃更改。
- **标签申请与审核**：支持申请添加公共标签；维护者审核通过后将其写入公共标签目录。增加申请去重、审核权限复核和目录并发冲突保护。
- **搜索与筛选**：支持题号、关键词、平台、作者、标签和平台原生难度组合筛选，并优化搜索结果排序。
- **账号与本地数据保护**：加强凭据保存、账号切换和本地记录归属校验，降低不同账号间记录误用或覆盖的风险。
- **启动与更新恢复**：修复旧更新事务阻塞启动的问题，并改进应用包更新后的恢复处理。
