# 拾题 v0.10.1 · 算法笔记

在 0.10.0 基础上新增算法笔记模块。

- 算法笔记独立分区：左侧 XCPC 算法树，父节点居中、左右展开，支持缩放、拖拽平移与逐层下钻，进入子节点后有「← 返回」。
- 算法树按 xcpc 图例着色：基础（入门）、初级（铜牌）、中级（银牌）、高级（金牌）、特级（争冠）、板子（浅紫）、常用、不常用；「堆排序」「希尔排序」按颜色表归入「不常用」。
- 按难度检索：工具栏难度下拉或直接输入难度词（如「银牌」「不常用」），只显示该颜色的节点并跨节点列出对应笔记。
- 公共笔记与个人笔记分离：公共笔记位于 `algorithms/notes/public/`，个人笔记位于 `algorithms/notes/personal/<GitHub-ID>/`；同步只取公共目录与当前账号目录。
- 管理员权限：可发布/编辑公共笔记并设置唯一精选；普通用户只能上传和编辑自己的个人笔记。
- 点击任意节点（含子节点）显示该节点下的笔记，点击笔记进入大字号阅读视图。
- 支持 Markdown 与内联 `$...$`、`$$...$$`、`\(...\)`、`\[...\]` 公式，代码块中的美元符号不参与公式解析。

版本号提升至 0.10.1，确保高于已安装的 0.9.3 与 0.10.0，避免安装时被判定为降级；用户数据（`auth.json`、`cache.json`、`local.json`、`contests.json`、`settings.json`）沿用 0.10 结构，升级不会重置本地记录。
